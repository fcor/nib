# Example image

Drop the bundled sample at `sample.jpg` in this directory.

- Prefer portrait images at least 1200 px tall.
- Include a broad tonal range, clear edges, and some fine detail.
- Keep the file reasonably small for the initial app download.
- Only use an image owned by this project or explicitly licensed for
  redistribution.

The UI should import this image so Vite fingerprints and bundles it with the
application.
